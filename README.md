# Gemma 4 E2B — Trained Model Evaluation Results

Evaluation-artifact repository containing validation output for a trained **Gemma 4 E2B** QLoRA experiment.

## Published result

- `validation_results_gemma4-e2b-qlora-run1.csv`

The CSV is the substantive artifact in this repository. The small `test*.txt` files are development/test files and should not be treated as experiment results.

## Reporting guidance

Any validation metric or checkpoint-selection claim should be recalculated from the published validation result file and tied to the exact training/evaluation configuration used for that run.

## Scope

This repository is an experiment-result archive, not a standalone model or application.
